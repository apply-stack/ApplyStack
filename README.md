# ApplyStack

ApplyStack is a backend API designed to help users find jobs and internships that match their skills and create CVs tailored to specific opportunities.

> **Work in progress.** This project is not yet complete. Some features are implemented, while others are still being designed or developed.

## Planned Features

- Manage education, work experience, projects, and skills.
- Browse job and internship listings.
- Compare user skills with job requirements and rank opportunities by compatibility.
- Create tailored CV versions using existing career information.
- Export CVs in JSON, LaTeX, and PDF formats.

## Current Status

Database models and JSON/LaTeX CV export functionality are in place. Many API endpoints remain drafts. Job collection, AI-assisted CV tailoring, and automatic PDF generation are not yet complete.

## Tech Stack

Python 3.12+, FastAPI, PostgreSQL, SQLAlchemy, Alembic, and Docker.
